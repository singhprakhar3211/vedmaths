Problem of the week

If  x + 1/x = 3,  find the value of  x5 + 1/x5.

No need to find x. Think about what you can build from x + 1/x.

Square it:  x² + 1/x² = 3² − 2 = 7

Cube it:  x³ + 1/x³ = 3³ − 3·3 = 18

Multiply the two:
(x² + 1/x²)(x³ + 1/x³) = x⁵ + 1/x⁵ + x + 1/x

So  x⁵ + 1/x⁵ = 7 × 18 − 3 = 123
